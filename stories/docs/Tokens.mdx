# Tokens

Every value in the system lives in one file, `src/tokens/tokens.ts`. This page reads that file, so it cannot drift from what ships. Switch the theme in the toolbar and every swatch follows.

Tokens come in three layers. Primitives are the raw palette and scales. Semantic tokens say what a value is for, and they are where light and dark diverge. Component tokens let a chapter change a component's shape without touching its code.
